# 2D Mobile Platformer Level (Game Developer Internship — Week 2)

A 2D mobile platformer game built with **Flutter** and the **Flame Engine**. Features moving platforms, collectible coins, patrolling enemy AI, life management, and touch control buttons designed for mobile screens[cite: 27].

---

## 📌 Features & Gameplay Mechanics

- **Physics Engine:** Gravity, jumping forces, and platform surface detection[cite: 27].
- **Moving Platforms:** Horizontally oscillating platforms that transport the player character upon standing on them[cite: 27].
- **Collectible Items:** Gold coins positioned across platforms that increment score upon pickup[cite: 27].
- **Patrolling Enemies:** Enemy character traversing back and forth; contact reduces player lives[cite: 27].
- **HUD & Touch Controls:** On-screen D-Pad and Jump buttons paired with life tracker hearts and score display[cite: 27].
